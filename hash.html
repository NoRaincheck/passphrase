how the selection works

The tool builds eight characters — two independent runs of the same three slots — and then picks four of them. Each run gives a symbol, a two-letter word and a digit, so there are 2 × 2 × 2 = 8 complete four-character hashes available. All eight carry the same 11.92 bits, so entropy does not decide it; what differs is how each one behaves on a typo.

The tiebreak is the edit this is really for: the same string with one character removed from the end — a truncated password, a filename cut short, a value pasted with a character missing. The tool computes that shorter string's hash as well, scores all eight candidates by how many characters differ, and shows the winner. More characters changed means the error is visible in the gap between the digits, not merely that something differs. About half the time the two strings settle on the same shape, and then the comparison is like-for-like and the property is the stronger 99.8%; the rest of the time the characters come from different runs, which is less controlled but still well ahead of no selection at all. 

#   string minus its last character
    what you see (both hashes chosen)   4/4 move 84.0%   3+/4 move 98.8%
    when both land on the same shape    4/4 move 92.6%   3+/4 move 99.8%
    one fixed run, no selection         4/4 move 60.2%   3+/4 move 92.7%

A fixed run is not enough, and that is a pigeonhole problem rather than a mixing problem: with six symbols, seventy-two words and nine digits, the three small slots each stay put about one edit in six, one in nine and one in seventy-two, so all three lining up by chance is common. Choosing the best of eight runs is what buys the margin.

Why not just print all eight? Eight characters carry 23.85 bits and would collapse to 15,116,544 distinct values instead of 3,888 — for 20,000 different strings, a fixed run gives only 3,864 distinct hashes while the full pool gives 19,983. That is a real gain, but it is a longer thing to read aloud and write down, so the page shows the selected four and leaves the pool available as pool(string).

What it is not. 11.92 bits is 3,888 values, so many strings share a hash and anyone can enumerate all of them instantly. This is a transcription checksum — it catches you mistyping your own string — and it is not protection against anyone who has read this file.

the function — copy this out 
const SETS  = ["!@#^&*", TWOS, "123456789"];
const SEED  = [0x811c9dc5, 0x9e3779b9, 0x85ebca6b];
const PRIME = [0x01000193, 0x85ebca77, 0xc2b2ae3d];

/* 32-bit multiply-and-mix: one changed character cannot cancel out */
function fmix(n){
  n ^= n >>> 16; n = Math.imul(n, 0x85ebca6b);
  n ^= n >>> 13; n = Math.imul(n, 0xc2b2ae35);
  n ^= n >>> 16;
  return n >>> 0;
}

/* one run: three slots over the whole string, independent key set per run */
function run(string, k){
  const cps = Array.from(string, ch => ch.codePointAt(0));
  return SETS.map((chars, s) => {
    let n = fmix(SEED[s] ^ Math.imul(k + 1, 0x9e3779b1)
                       ^ Math.imul(cps.length + 1, PRIME[s]));
    for (let j = 0; j < cps.length; j++)
      n = fmix(fmix(Math.imul(n, PRIME[s]) ^ (cps[j] + 1))
               + Math.imul(j + 1, 0x165667b1));
    return chars[(n >>> 16) % chars.length];
  });
}

/* the pool: two runs, six characters */
function pool(string){ return [...run(string, 0), ...run(string, 1)]; }

/* eight complete hashes to choose from: one symbol, one word, one digit each */
const SHAPES = [[0,1,2], [0,1,5], [0,4,2], [0,4,5],
                [3,1,2], [3,1,5], [3,4,2], [3,4,5]];

function hashOf(string){
  const p = pool(string);
  if (!string.length) return SHAPES[0].map(i => p[i]).join("");
  /* the string one character shorter -- the edit this hash is tuned for */
  const q = pool(string.slice(0, -1));
  let best = -1, bestShape = SHAPES[0];
  for (const shape of SHAPES){
    const a = shape.map(i => p[i]).join(""), b = shape.map(i => q[i]).join("");
    let d = 0;
    for (let i = 0; i < 4; i++) d += a[i] !== b[i];
    if (d > best){ best = d; bestShape = shape; }
  }
  return bestShape.map(i => p[i]).join("");
}

TWOS is the same 72 two-letter words the passphrase page uses, embedded below. No imports, no dependencies. Array.from walks code points, so an emoji counts as one character.
